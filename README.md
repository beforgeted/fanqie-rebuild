# 番茄书库重构

让番茄网页版找书更省心：关键词屏蔽、自动记录和列表对齐。

当前版本：**1.13.8**。支持 Chrome／Edge 共用的原生扩展，以及油猴脚本；拖入恢复目前用于扩展版。

## 已有功能

- 点击书库卡片文字区可展开简介：在书籍旁打开独立阅读框，开关时保留书库位置；完整简介内部滚动，底部直接加入候选或标记不想看。

- 详情页“开始阅读／加入书架”附近可标记候选、不想看，并支持清除、撤销。
- 书库卡片提供快捷标记，多标签页自动同步；不想看的书隐藏后继续补位。
- 网站导航“我的选书”在当前标签页切换到独立页面：候选使用带封面的列表与完整简介双栏，封面右上角显示磨砂同步标识；支持搜索、同步状态筛选和可选备注，切回书库时恢复原分类、排序、已加载列表和浏览位置。
- 首页／书库／书架进入“我的选书”复用当前页面与顶部导航，统一使用白色背景与同一套页面布局，使用官网选中和悬停样式；先显示已有候选资料，进入后按需读取完整简介、缺失封面与官方同步状态，网络失败仍可读已有简介。
- 点击左侧候选后可用 ↑／↓ 切换；右侧“下一个”按当前搜索／筛选结果顺序前进，到末尾停止，输入备注和阅读简介时保留正常按键操作。
- 书库与排行榜右侧原站工具栏的“筛书设置”直接打开右侧抽屉，包含关键词规则与屏蔽记录。方案管理和分组整理按需展开，覆盖原页面，不挤动书流。
- 筛书抽屉内部滚动，支持关闭按钮、Esc 和点击背景关闭；规则与记录之间切换保留词表草稿，关闭后丢弃未保存修改。

- 书库无限滚动：接近底部自动加载，支持暂停、手动加载、失败重试及关闭回退。
- 后续页面继续执行关键词屏蔽、自动记录和对齐补位，按书籍 ID 去重。

- 按书名和简介屏蔽关键词，可自行编辑词表、暂停或临时显示。
- 屏蔽词逐个显示为标签，编辑时可单独删除；支持用换行、逗号、顿号、分号或制表符一次输入多个词，自动忽略重复词和空项。
- 直接“保存并应用”即可录入输入框中的新词；Ctrl／Cmd+Enter 可先加入草稿标签，词内空格不作为分隔符。
- 默认排除原神、崩铁、星穹铁道、星铁、崩坏3、崩坏三、绝区零、鸣潮。
- 适配书库与排行榜的特殊字体编码，减少乱码造成的漏匹配。
- 隐藏命中书籍后自动补位，保持各列间距一致。
- 自动保存命中书籍，按书籍 ID 去重，记录作者、命中词及首次／最近遇到时间。
- 支持记录搜索、待处理筛选、复制书名、导出 CSV 和手动处理标记。
- 关键词、屏蔽记录与候选保存在本地。主动同步时，只向番茄官方发送所选书籍和分组操作，不上传到第三方。

## 选书方案与关键词分组

右侧“筛书设置”直接进入规则抽屉，顶部可切换选书方案。日常只需在“不想看到哪些内容？”输入关键词，例如“原神，崩铁，鸣潮”，直接点击“保存并应用”。旧词表自动显示为“默认方案”的“原有词表”，首次保存时兼容升级，不清空既有数据。

- 展开“管理方案 → 新建或复制方案”填写名称，可复制当前设置（包含草稿）或新建空白方案；复制后原方案不受影响。编辑方案名称后点击“保存并应用”改名，删除方案需确认且至少保留一套。
- 每个方案独立保存屏蔽词组、启用屏蔽和匹配简介开关。当前方案在本浏览器的已打开页面间同步，分类、排序和无限滚动开关保持原来的独立设置。
- 展开“整理分组”后，新建词组并填写组名，例如“星穹铁道别名”，加入“崩铁、星铁、星穹铁道”；任意一个词命中即生效。整组可停用，词仍保留；不自动补充别名。
- 勾选已有词标签，选择目标组并点击“移动勾选词”，再保存。批量录词及逐词删除继续支持；只允许删除空组，避免误删词表。
- 未保存时切换方案会提示保存、放弃或取消。保存失败不改变生效规则；另一页修改后保留本页草稿并提示冲突，可显式放弃草稿、载入最新设置。

切换只重新筛选已有卡片，不清空已加载书流。候选、不想看、备注、屏蔽记录和官方同步状态共用原有数据，不按方案复制或删除。新方案的过滤结果会继续记入同一屏蔽记录。

性能方面仅整理当前方案的启用词组，预先规范化关键词，每个标题／简介每次扫描只规范化一次，匹配结果同时用于隐藏和记录。整页启动仍受官网网络、渲染和卡片数量影响。

## 在书库阅读完整简介

点击卡片中的作者、字数、简介、更新时间或这些文字之间的空白处，即可在当前书籍旁阅读；已移除原“展开简介”小按钮，卡片下方保留候选、不想看及清除标记操作。选中文字、点击书名链接或操作按钮不会误触阅读框。同一时间只显示一本，点击其他卡片的文字区即可切换。点击“收起”、按 Esc 或点击框外可关闭。滚动书库也会收起，卡片不会因简介变高，原页面不跳转。书名、封面及框内“查看详情”仍可打开详情页。

先显示列表中的简介，再从该书官方详情页核对完整内容；失败时保留列表文本并提供重试。已取得的简介仅在当前标签页短暂缓存，刷新后不保留。正文独立滚动，操作区固定在底部；支持方向键、翻页键及 Home／End。

加入候选后阅读框保持打开；标记“不想看”后收起、隐藏书籍并补位，页面底部提供撤销。候选仍保存在本地，加入官方“待看”需在“我的选书”中主动同步。

## 集中复筛候选

打开导航“我的选书”进入独立候选页面，左侧选择书籍，右侧直接阅读完整简介。两侧独立滚动；切换书籍、更新同步状态和保存备注时，保留左侧列表位置。封面来自官方详情数据，旧记录在列表可见时按需补齐，失败时显示占位并保留已有简介。只解析页面数据，不执行返回页面的脚本。

封面右上角标识区分已同步、未同步、等待同步、同步中和失败；状态按当前番茄账号核验。可筛选全部候选、未同步、已同步、同步失败；未同步包含失败或尚在处理的书籍。勾选和“全选当前结果”仍用于原有批量同步。

左侧候选卡片保留勾选、封面与同步角标，移除重复的“加入官方待看”按钮。阅读区底部提供“加入官方待看／不想看／移出候选／查看详情”，顶部保留批量同步。同步成功保留候选记录；移出候选只取消本地候选，不等于不想看，也不删除官方书架。移出和不想看均可撤销。

“留下一句备注”是可选功能，输入后点击“保存备注”；保存失败保留草稿。同页切换书籍或进入数据管理后返回可继续编辑草稿，刷新或关闭网页前应先保存。备注仅存本地，不上传官方书架；保存备注不改变候选排序。另一标签页同时修改时提示冲突，由用户核对后载入最新备注，不静默覆盖。

## 候选与官方待看

本地“待看”现更名为“候选”，沿用原有数据，无需重新添加。

1. 在书库或详情页标记“候选”，从导航“我的选书”在当前标签页切换到候选清单。
2. 点击单本“加入官方待看”，或勾选多本后批量加入；“全选当前结果”只选择当前搜索结果。
3. 若书籍已在其他官方分组，界面会列出书名和原分组，确认移动后再执行。
4. 已在官方“待看”的书直接核验；不在书架的书先加入书架，再移入“待看”。没有该分组时，随第一本书创建。
5. 逐本显示等待、同步中、已同步或失败；点击“重试失败”前会再次读取官方书架，避免重复写入。

成功后同一番茄账号的手机书架可同步。清除候选或改为“不想看”只影响本地筛书，不移除官方书架中的书。

同步使用当前网页的登录状态，不要求复制 Cookie；同步记录按账号保存。仅在用户点击同步后写入，打开清单只核对官方状态。请在同步期间保持标签页打开；意外关闭后可重新打开并刷新状态或重试核验。跨标签页同步使用 Web Locks 串行执行，需要支持该能力的浏览器。

目前不提供官方分组改名、删除或任意分组管理。官方接口可能变化，写入后必须回读核验；AI 分析仍在后续阶段。

详细步骤及升级、备份恢复方式见 [安装与更新](docs/安装与更新.md)，版本变化见 [更新说明](docs/更新说明.md)。已有用户更新时覆盖原扩展目录，保持开发者模式开启，在原扩展卡片点“重新加载”后刷新网页；不要先卸载或从新版本目录另装一份。

## Chrome / Edge 安装

1. 下载仓库 ZIP 并解压到固定位置，或使用 Git 克隆。
2. 在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`，开启右上角“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择仓库里的 **chrome-extension** 文件夹。
4. 打开或刷新 [番茄书库](https://fanqienovel.com/library)。
5. 点击原站右侧工具栏“筛书设置”直接编辑关键词，切换“屏蔽记录”查看历史；导航栏“我的选书”在当前标签页查看候选／不想看。

仓库包含可直接加载的扩展文件，安装使用无需 Node.js。请保留解压目录。更新后在扩展管理页点击重新加载，再刷新番茄页面。

## 备份与迁移

打开“我的选书”独立页面，点击右上角“数据管理”。

1. 在原电脑点击“一键导出”，保留下载的 JSON 配置包。
2. 在另一台电脑的 Chrome 或 Edge 加载同一个 chrome-extension 文件夹，打开番茄网站。
3. 进入“我的选书 → 数据管理”，把文件拖进导入框，或点击选择文件。无冲突时直接恢复，有冲突时选保留本机、采用备份；方案也可两份都保留，再确认导入。

配置包包含全部选书方案、词组与启用开关、无限滚动设置、候选／不想看／清除标记、备注及屏蔽记录。新安装恢复备份的当前方案；已有设置默认合并并保持本机当前方案，重复导入去重。确认前不会写入冲突数据，确认时会重新核对，避免覆盖另一页刚修改的备注。

备份不包含 Cookie、账号凭据、官方待看分组 ID 或“已同步”缓存。另一台电脑需自行登录番茄；在候选清单刷新官方状态后重新核验，不会因导入自动加入、移动或删除官方书架。配置包仅在浏览器本地读取，不上传服务器。

格式为 fanqie-rebuild-backup v1，单文件上限 10 MB；未知版本、无效字段会拒绝导入，存储空间不足可保留文件重试。油猴版可导出，拖入导入目前限定 Chrome／Edge 扩展版，以使用单次批量存储写入。

已用独立测试目录验证 Chrome 157 → Edge 158 拖入、Edge 158 → Chrome 157 文件选择恢复，覆盖安装、存储、导出下载和导入；测试使用离线页面，不操作真实账号书架。两浏览器共用同一份扩展产物，参见 [Microsoft 的 Chrome 扩展迁移说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/developer-guide/port-chrome-extension)。

## 油猴安装

在 Tampermonkey 中新建脚本，粘贴 `fanqie-keyword-filter.user.js` 的全部内容并保存，再刷新番茄页面。同一浏览器请只启用一种版本，避免重复运行。

## 本地开发

需要 Node.js 22.13 或更新版本，以及 npm。

```sh
npm ci
npm run build
npm test
```

源码按功能整理在 **src/**，构建、测试和文档分别位于 **scripts/**、**tests/**、**docs/**。核心规则、存储、备份和官方接口可单独测试；页面按书库、规则、候选、简介、同步等功能归类。详细边界和后续 AI 接入说明见 [架构与扩展](docs/架构与扩展.md)。

- 修改 src 下的源文件后运行 npm run build；根目录用户脚本与 chrome-extension 是生成产物，不直接编辑。
- npm run package：构建、检查并生成 dist 中的 Chrome／Edge 通用安装包和 SHA256。
- npm run test:release：从最终 ZIP 验证历史升级、重启和完整模拟流程，需完整 Git 历史、Chrome／Edge 及本地调试运行库。
- npm test：独立模块测试，以及记录、无限滚动、官方同步、简介、候选复筛、方案和备份回归。仅模拟服务，不写真实书架。
- npm run check：检查产物是否与源码一致、模块导入、脚本语法及版本号。
- npm run test:browsers：Windows 上真实 Chrome／Edge 双向迁移测试，需要本地 devtools-runtime 的 Chrome DevTools MCP 运行库和两个浏览器。使用独立临时目录与模拟页面，不读取个人浏览器数据。

分析服务接口已预留，默认未配置，不发起 AI 请求；模型接入和分析界面仍在后续计划中。原安装目录和既有数据不变。

## 范围与限制

目前支持官网书库、排行榜和书籍详情页；官方书架页也可打开候选清单。不直接控制手机 App，不修改正文或搜索结果。无限滚动从地址栏当前页开始，不自动补抓之前的页。刷新后从该页重新获取列表；浏览位置恢复已取消。连续三页没有新增可见书籍时会暂停，可点击“继续查找”。

“我已处理”仅代表本地手动标记，不会向番茄提交“不感兴趣”，也不会同步到手机。卸载扩展可能导致本地记录丢失，重要资料可在“我的选书 → 数据管理”导出配置包。

关键词匹配可能误伤否定描述，也可能漏掉仅写角色名的书籍。网站改版或更换字体后，适配可能需要更新。

### 选书面板布局（1.9.2）

标题与分类标签合并为一行，搜索、同步筛选和批量操作采用紧凑工具栏，窄窗口自动换行。状态和撤销提示统一放到底部；候选列表、完整简介获得更多可用高度。保留封面角标、备注、单本及批量同步，原书库和列表的滚动位置保持不变。

### 关键词输入界面简化（1.10.1）

主界面突出输入框、示例、已有标签与保存按钮。“管理方案”“整理分组”“更多设置与说明”按需展开；词标签的勾选框仅在整理分组时显示。分组有多组或已停用时显示当前组，避免把词加错位置。已有存储和匹配规则保持不变。


### 独立选书页与筛书抽屉（1.13.0）

[我的选书](https://fanqienovel.com/library?fq_view=selection#later) 可直接打开、收藏和刷新，需启用本扩展或用户脚本。复用官网导航及同源登录态；未启用时此地址仍是官方书库，不是独立托管网站。候选／不想看属于选书页，规则／屏蔽记录属于书库侧边抽屉，备份迁移放在选书页右上角“数据管理”。

候选列表和简介独立滚动，数据管理往返保留本页搜索、当前书籍及列表位置；批量同步按钮在勾选后出现。独立页不启动书库无限加载、不记录被隐藏的原生书库卡片。原有数据、备注、跨标签页通知、官方同步和备份格式沿用。


### 同标签页切换与书库现场保留（1.13.1）

点击导航“我的选书”在当前标签页切换，不再新建标签页。从书库进入时暂存当前分类／排序／页码 URL、已加载书流及滚动位置；点击导航“书库”或使用浏览器后退可恢复。前进可再次进入选书页，候选和备注继续正常使用。离开书库期间暂停继续加载，取消未完成的加载请求并忽略迟到结果；返回后仍从原来的下一页继续。

这些浏览状态仅在当前标签页内存中保留，刷新、关闭标签页或完整跳转离开本站后不重建之前的无限书流。直接打开选书地址仍可用；从首页、书架等非书库页面进入也使用当前标签页。

数据管理支持预览并清理自动屏蔽记录，执行前逐包下载备份并确认保存。候选、不想看、有备注书籍及规则受保护；恢复时依次导入全部备份包。仅 Chrome／Edge 扩展支持清理。
