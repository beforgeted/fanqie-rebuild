# 番茄书库重构

在电脑上更方便地筛选番茄小说：屏蔽不想看的题材，留下感兴趣的书，挑好后同步到手机。

适用于 **Chrome / Edge**，当前版本 **[1.13.8](https://github.com/beforgeted/fanqie-rebuild/releases/tag/v1.13.8)**。功能融入番茄原网页，安装后即可使用。

## 找书可以更顺手

- **连续逛书库**：往下滑动就能加载更多书，按关键词隐藏不感兴趣的内容，剩下的书自动补位。
- **看完简介再决定**：点击书籍文字区阅读完整简介，感兴趣就加入“候选”，不喜欢就标记“不想看”。在“我的选书”里逐本复筛，也可以留下备注。
- **选好了，手机接着看**：把挑中的书单本或批量加入官方“待看”分组，同一番茄账号的手机书架即可同步。

例如，想看动漫衍生但不想看二游同人，可以在“筛书设置”中输入 `原神，崩铁，鸣潮`，保存后继续浏览。屏蔽词可以自行增删，也能为不同阅读偏好保存多套方案。

> 逛书库 → 看简介 → 留候选 → 集中挑选 → 加入官方待看

## 开始使用

1. [下载 Chrome／Edge 安装包](https://github.com/beforgeted/fanqie-rebuild/releases/download/v1.13.8/fanqie-rebuild-v1.13.8-Chrome-Edge.zip)，解压到准备长期保留的位置。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择解压目录中的 **chrome-extension** 文件夹。
4. 打开或刷新 [番茄书库](https://fanqienovel.com/library)。右侧“筛书设置”管理关键词，顶部“我的选书”查看候选。

安装无需 Node.js。已有用户更新时，覆盖**原安装目录**，在原扩展卡片点击“重新加载”，再刷新网页。完整步骤见 [安装与更新](docs/安装与更新.md)。

## 数据与手机同步

候选、备注、屏蔽词和屏蔽记录保存在当前浏览器本地；只有你主动加入官方“待看”的书籍会同步到手机。换电脑或浏览器时，在“我的选书 → 数据管理”导出配置，再到另一端拖入恢复。卸载前请先备份。

关键词可能误屏或漏屏，可以临时显示隐藏的书，并查看屏蔽记录。网站改版可能影响适配；本项目为非官方辅助工具。
