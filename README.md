# 番茄书库重构

让番茄网页版找书更省心：关键词屏蔽、自动记录和列表对齐。

当前版本：**1.3.1**。支持 Chrome 原生扩展和油猴脚本。

## 已有功能

- 按书名和简介屏蔽关键词，可自行编辑词表、暂停或临时显示。
- 默认排除原神、崩铁、星穹铁道、星铁、崩坏3、崩坏三、绝区零、鸣潮。
- 适配书库与排行榜的特殊字体编码，减少乱码造成的漏匹配。
- 隐藏命中书籍后自动补位，保持各列间距一致。
- 自动保存命中书籍，按书籍 ID 去重，记录作者、命中词及首次／最近遇到时间。
- 支持记录搜索、待处理筛选、复制书名、导出 CSV 和手动处理标记。
- 配置与记录保存在本地，不上传到其他服务。

## Chrome 安装

1. 下载仓库 ZIP 并解压到固定位置，或使用 Git 克隆。
2. 在 Chrome 打开 `chrome://extensions/`，开启右上角“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择仓库里的 **chrome-extension** 文件夹。
4. 打开或刷新 [番茄书库](https://fanqienovel.com/library)。
5. 点击右下角“关键词屏蔽”调整设置；点击“屏蔽记录 / 待处理清单”查看记录。

仓库包含可直接加载的扩展文件，安装使用无需 Node.js。请保留解压目录。更新后在扩展管理页点击重新加载，再刷新番茄页面。

## 油猴安装

在 Tampermonkey 中新建脚本，粘贴 `fanqie-keyword-filter.user.js` 的全部内容并保存，再刷新番茄页面。同一浏览器请只启用一种版本，避免重复运行。

## 本地开发

需要 Node.js 22.13 或更新版本，以及 npm。

```sh
npm ci
npm run build
npm test
```

- `fanqie-keyword-filter.user.js`：屏蔽逻辑、设置界面、记录清单与布局修正。
- `history-background.js`：Chrome 后台存储，串行处理多标签页记录更新。
- `build-chrome-extension.cjs`：从源文件生成 Chrome 扩展。
- `chrome-extension/`：构建产物，可直接加载；修改源文件后需要重新构建。
- `verify-history.cjs`：记录持久化、去重、处理标记、导出与异常恢复测试。

## 范围与限制

目前支持官网书库和排行榜，不处理手机 App、正文或搜索页。只过滤已经加载的书籍；**无限滚动尚未实现**。

“我已处理”仅代表本地手动标记，不会向番茄提交“不感兴趣”，也不会同步到手机。卸载扩展可能导致本地记录丢失，重要记录可先导出。

关键词匹配可能误伤否定描述，也可能漏掉仅写角色名的书籍。网站改版或更换字体后，适配可能需要更新。

## 后续计划

完整设想、功能清单、建议阶段与验收标准见 [项目计划](项目计划.md)。目标是逐步构建“番茄选书台”，打通浏览、筛选、候选比较与试读反馈。

- [ ] 第一阶段：无限滚动、位置恢复、详情侧栏与选书状态。
- [ ] 第二阶段：偏好方案、别名词组、筛选依据与候选比较。
- [ ] 第三阶段：自然语言筛选、带证据的 AI 信息整理与比较。

以上为建议路线，尚未实现或承诺排期；当前可用功能以“已有功能”为准。
