# 安装、更新与数据恢复

适用版本：1.13.8，Chrome／Edge 扩展。两个浏览器使用同一个安装包。

## 第一次安装

1. 解压“番茄书库重构-v1.13.8-Chrome-Edge.zip”，把其中 chrome-extension 文件夹放到准备长期保留的位置。不要直接在压缩包或临时下载目录里加载。
2. Chrome 打开 chrome://extensions/，Edge 打开 edge://extensions/，开启“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择包含 manifest.json 的 chrome-extension 文件夹。
4. 打开 https://fanqienovel.com/library 或刷新已打开的番茄页面。右侧可打开“筛书设置”，导航栏可打开“我的选书”。

源码仓库安装同样选择 chrome-extension，无需安装 Node.js；只有修改源码和重新构建才需要开发环境。不要同时启用本扩展和同功能油猴脚本，以免出现两套控件与不同存储。

## 已安装用户更新：保留原目录、原扩展

1. 在“我的选书 → 数据管理”导出备份；备注应先点“保存备注”，未保存草稿不进入备份。
2. 下载新安装包，解压到另一处。把新版 chrome-extension 文件夹内的文件复制到**原来加载扩展的文件夹**，覆盖同名文件。不要把新文件再套进一层 chrome-extension 子目录。
3. 回到扩展管理页，保持“开发者模式”开启，在已有扩展卡片上点击“重新加载”图标。不要先点“移除”，也不要从新的版本目录另装一份。
4. 等待扩展重新加载完成，核对扩展显示的版本，再刷新番茄页面；确认候选、备注和规则存在即可继续使用。更新前打开的旧网页需要刷新才能使用全部新版逻辑。

未打包扩展的身份与安装路径有关。保持原路径、原扩展卡片和浏览器个人资料，是保留同一份本地数据的关键。修改仓库位置或更换安装路径前先备份。仅覆盖文件和重启浏览器不能代替扩展的“重新加载”，否则后台仍可能运行旧逻辑。普通重启浏览器会保留已保存数据；未打包扩展通过上述步骤手动更新，不会自动安装新版。

## 数据保存在哪里

候选、不想看、已保存备注、筛选方案、屏蔽词、自动屏蔽记录及同步状态存放在当前浏览器个人资料的扩展本地存储中，不在安装包内。Chrome 和 Edge、不同浏览器个人资料、不同电脑分别保存。

主动加入官方“待看”的书籍随同一番茄账号同步到手机。个人备注、关键词和本地候选不会因此同步到手机。登录番茄不会自动迁移本扩展数据。卸载扩展、删除浏览器个人资料或清除扩展存储可能丢失本地资料。

## 换浏览器／换电脑

1. 旧电脑打开“我的选书 → 数据管理”，点击“一键导出”，保留生成的 JSON 文件。
2. 新电脑安装扩展后，在同一入口拖入文件，或点击文件区域选择 JSON。
3. 有冲突时核对后选择保留本机、采用备份；方案可两份保留。导入采用合并，不清空整库。
4. 官方待看状态由新浏览器的当前番茄账号重新核验。备份不包含 Cookie、登录凭证和按账号保存的同步状态。

单包导入上限 10 MB。如果普通导出提示过大，可在下面的“清理屏蔽记录”先点“预览”，逐个下载生成的分包；**下载备份不需要执行清理**。分包包含个人标记、设置和屏蔽记录，每包都能独立导入，恢复完整资料需依次导入全部分包。不要只保留第一个文件。特别大的单套设置仍可能超过上限，此时会中止备份并提示错误。

## 清理及恢复

“数据管理 → 清理屏蔽记录”默认筛选 90 天未再次遇到的记录，也可选 30／180 天或全部；可限定为“我已处理”。先预览书名、下载所有备份并确认保存，再执行清理。

只删除自动屏蔽记录。候选、不想看及有备注书籍的关联记录受保护，其他个人资料、规则和官方书架不变。预览后状态变化的记录会跳过；失败可重新预览后重试。以后重新浏览遇到同书时仍会生成新记录。

需要恢复时，在上方导入清理前备份；分包须全部依次导入。若此后修改过候选或备注，应在冲突确认中保留想要的版本，避免用旧备份覆盖自己的新判断。

## 常见情况

- 没有新版控件：检查扩展已启用，核对版本，然后刷新番茄页面。
- 更新后像是没有数据：先核对浏览器个人资料、扩展 ID 和原安装路径；不要急着卸载旧扩展。可从旧入口导出后，在新入口导入。
- 官方待看同步失败：核对网页登录和当前账号，使用“刷新同步状态”或重试；不要据此删除候选。
- 手机没看到备注或关键词：这些是扩展本地资料；手机同步范围是主动加入的官方待看书籍。
