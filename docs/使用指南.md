# 使用指南

## 设置不想看到的内容

在书库或排行榜右侧点击“筛书设置”，输入关键词并“保存并应用”。支持用换行、逗号、顿号或分号一次输入多个词，例如“原神，崩铁，鸣潮”；重复词会自动去除，词内空格保留。已有词以标签展示，可单独删除。

默认词表用于排除部分二游题材，可按自己的喜好修改。“同时检查简介”会扩大匹配范围，也可能误伤只是在简介中提及关键词的书。“临时显示”可以查看隐藏的书，“屏蔽记录”保存曾经命中的书籍，供搜索、复制或导出。

需要多套偏好时，展开“管理方案”新建或复制；例如为动漫衍生和其他分类分别设置词表。方案中的词组可整组启停，也可把同一题材的别名放在一组。切换方案会重新筛选已加载书籍，候选和备注继续共用。

输入框和标签中的改动需要保存才会生效。切换方案遇到未保存修改时，可以选择保存、放弃或取消。

## 连续浏览和阅读简介

书库接近底部时会加载下一页，新增书籍继续按当前规则过滤。可以暂停自动加载、手动加载；失败时可重试。连续三页没有新增可见书籍会暂停，点击“继续查找”可接着找。也可以在筛书设置中关闭无限滚动。

点击卡片中的作者、字数、简介或这些文字之间的空白处，打开完整简介阅读框。阅读框中可以直接加入候选或标记“不想看”；点“收起”、框外或按 Esc 关闭。书名、封面和“查看详情”保留打开详情页的操作。

切到“我的选书”再返回书库，会保留原分类、已加载书籍和浏览位置。刷新或关闭页面后，会重新获取当前书库页。

## 把感兴趣的书留下来

在书库、简介框或书籍详情页标记“候选”，即可在“我的选书”集中查看。“不想看”会隐藏该书；标记支持清除和撤销。

候选清单左侧选书，右侧看完整简介。可以搜索书名或作者，按同步状态筛选。点击左侧候选后，用 ↑／↓ 切换，也可以点击右侧“下一个”；到最后一本停止。

“留下一句备注”是可选的，写完需点击“保存备注”。切换书籍或往返数据管理会保留未保存草稿，刷新或关闭页面前请先保存。另一标签页修改了同一备注时，会提示你核对。

“移出候选”只取消候选标记，已保存的备注仍保留；它也不会移除官方书架里的书。本地候选仍可能命中关键词，候选清单会保留这本书，方便继续查看。

## 挑好后加入官方待看

先在番茄网页登录账号，再在候选阅读区点击“加入官方待看”；也可以勾选多本后批量加入。首次需要时会创建官方“待看”分组；同账号手机书架可同步看到。

若书籍已在其他官方分组，会先询问是否移动。同步失败可重试，重试前会再次核对书架，避免重复添加。同步期间请保持页面打开；中途关闭后，可以重新打开并刷新同步状态。

打开候选清单只核对官方状态，主动点击同步才会写入。备注和屏蔽词只留在本地，不上传到官方书架。“不想看”和屏蔽记录中的“我已处理”都不会向官方提交“不感兴趣”。

## 备份与清理

在“我的选书 → 数据管理”导出配置，另一台电脑或另一个浏览器安装扩展后，拖入文件即可合并恢复；有冲突时自行选择保留哪一份。

清理入口只删除自动屏蔽记录，先预览、下载备份再确认。候选、不想看、有备注书籍的关联记录及规则受到保护。分包恢复等具体步骤见 [安装与更新](安装与更新.md)。

## 油猴脚本

也可在 Tampermonkey 中新建脚本，粘贴仓库根目录 fanqie-keyword-filter.user.js 的全部内容并保存。油猴版可导出配置；导入和安全清理目前支持 Chrome／Edge 扩展版。一个浏览器只启用一种版本，避免重复运行和分开保存数据。
